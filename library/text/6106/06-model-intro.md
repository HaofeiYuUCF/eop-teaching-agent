> • Functionally, an advanced modern air quality 
> model is comprised of four layers
> – Physical layer: a simplified physical model to 
> represent actual processes (with assumptions)
> – Math layer: mathematical representation of the 
> physical layer (with more assumptions)
> – Numerical layer: numerical solution to math layer
> – Code layer: computer code for numerical layer
> • Not an accurate representation

> SMOKE
> • SMOKE (Sparse Matrix Operator Kerner Emissions) is a 
> widely used emission model in the US
> – Home: https://www.cmascenter.org/smoke/

> • When only total emission is known
> – Spatial surrogate: used to spatially allocate emission
> – Temporal profile: used to temporally allocation emission
